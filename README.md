# ダンジョンコレクター

スマートフォンのブラウザで遊べる、見下ろし型・マス目移動・ターン制のローグライクRPGです。
ランダムに生成される迷宮を探索し、敵ごとのレア装備を集め、合成して強くしていきます。

## 遊び方

- 下の十字キーで移動します。押し続けると連続で移動し、敵が見えたり攻撃を受けたりすると止まります。
- 隣の敵の方へ進むか「攻撃」を押すと、正面の敵を攻撃します。
- 「向きを変える」を押してから方向を選ぶと、ターンを使わずに向きだけを変えられます。
- 「スキル」「アイテム」で一覧を開き、「使う」を押すとすぐに発動します。
- 右上の小さな地図をタップすると、大きな地図が開きます。
- 各迷宮は全10F。10Fのボスを倒すと次の迷宮が解放されます。
- 倒れても、レベル・装備・アイテム・図鑑・実績はすべて残ります。次の挑戦は1Fからです。
- 探索中に「撤退」ボタンから「中断」を選ぶと、今の階のままホームに戻れます。ホームの「探索を再開」で続きから遊べます（中断中は装備・アイテム・合成を変更できません）。
- 探索の途中でブラウザを閉じた場合も、同じように続きから再開できます。

パソコンでは、矢印キー（またはWASD）で移動、スペースで攻撃、`.` で待機、Shift＋矢印で向きだけ変更、`K` でスキル、`I` でアイテム、`M` で地図です。

## GitHub Pagesでの公開手順

1. このフォルダの中身をリポジトリの直下に置いて push します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** を「Deploy from a branch」にし、ブランチ（例：`main`）とフォルダ `/ (root)` を選んで保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。

## オフラインとホーム画面への追加

- 一度オンラインで開くと、ゲーム本体がスマートフォンに保存され、以降は電波がなくても遊べます（`sw.js` が担当）。
- ブラウザのメニューから「ホーム画面に追加」すると、アプリのように全画面で起動できます（`manifest.webmanifest` が担当）。
- ゲームを更新したときは、`sw.js` の先頭にある `CACHE='dungeon-v12'` の数字を上げると、遊んでいる人の端末にも確実に新しい版が届きます。

## アップデートの出し方

1. `index.html` などを書き換えて push します。
2. `sw.js` の先頭にある `CACHE='dungeon-v…'` の数字を1つ上げます（遊んでいる人の端末に新しい版を確実に届けるため）。
3. 遊んでいる人は、ゲームを開き直すと新しい版になります（オフライン用の保存があるため、反映に2回ほど開き直しが必要なことがあります）。

セーブデータは、同じアドレス（`https://<ユーザー名>.github.io`）で遊んでいる限り、アップデートしても引き継がれます。セーブデータの形を変える場合は、`index.html` の `SAVE_VER` を上げ、`load()` の中に古いデータを変換する処理を追加してください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（画面・処理・ドット絵・音をすべて含む1ファイル） |
| `sw.js` | オフライン用の保存処理 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色 |
| `icons/` | アプリのアイコン（192px・512px） |

外部ライブラリは使っていません。BGMと効果音はブラウザの中で合成しているので、音声ファイルもありません。

## セーブデータ

進行データは、遊んでいるブラウザの中（localStorage）に保存されます。別の端末やブラウザには自動では引き継がれません。

ホームの「設定」→「データ」で、セーブデータを文字列として書き出し（バックアップ）、別の端末やブラウザで読み込んで復元できます。iPhoneのSafariでは、ホーム画面に追加せずに長く開かないとデータが消えることがあるため、ときどきバックアップしてください。

## 開発用の設定

アドレスの末尾に `#dev` を付けて開く（例：`https://<ユーザー名>.github.io/<リポジトリ名>/#dev`）と、「設定」に開発用の欄が表示されます。ふだんの遊び方では表示されず、効果もありません。

- **全ダンジョン開放**：ボスを倒していなくても、すべての迷宮に挑戦できます。
- **ボスから挑戦**：各迷宮の10F（ボス部屋）から始められます。
